# 步骤 2：大纲与文案策划

目标：把「有多少内容」翻译成一张**页序表**。这张表定死以后，素材、排版、页码全都跟着它走。产出一张表，不是版面。

## 输入是什么

步骤 1 的**素材清单**和**缺口列表**，加上用户给的品牌故事、卖点、规格、条款。此时还没有任何 HTML。

先回答三个问题：这本图册给谁看（经销商 / 终端 / 展会）、有几个章节、每章讲什么。答案决定页数规模。

## 页序表怎么排

页序表是一张表，一行一页，四列不能少：

| 列 | 内容 | 说明 |
| --- | --- | --- |
| 页码 | `01`、`02` … | 两位数字，将来就是 HTML 文件名的前两位 |
| 文件名 | `01-cover.html`、`11-ch01-frame-a.html` | 小写，短横线分隔，只用 `[a-z0-9-]` |
| 页面用途 | 封面 / 目录 / 章节页 / 产品页 / 资质 / 封底 | 决定用哪套版式 |
| 页脚页码 | `P1`、`P11` … | 印在页脚的可见页码，通常等于文件页码 |

骨架（可直接套用换内容）：

封面 → 目录 → 关于我们 → 合作方式 → 生产流程 → 工厂与品质 → 资质证书 → 商务条款 → 分章产品页 → 封底

参考规模：前置页 1–10，之后每个章节 10 页上下，产品页按型号排，最后一页封底。

## 章节页与产品页

- 每个章节先一张**章节页**（深色底、章节号、章节名），章节内页码连续。
- 产品页按型号排，一个型号一到两页：主图 + 细节图 + 规格表 + 卖点。放不下就拆成两页，**不要为了塞进一页把字号压到 9 pt 以下**。
- 型号顺序按用户给的目录顺序，不要自己重排。

## 页数变了怎么办

页数必须同时改**三处**，少一处就 `check_pages.py` 不通过：

1. `pages/` 下新增或删除 HTML 文件（文件名前两位 = 页码）
2. `render.cjs` 里的页面清单（一行一个文件名）
3. `build_catalog_html.py` 里的 `LABELS`（文件名 → 章节目录标签）

改完跑一遍 `sync_page_numbers.py` 和 `check_pages.py`，页码和文件名立刻对齐。

## 文案写作要点

- 一页一个主张。标题说结论，正文给证据（参数、认证、工艺）。
- 规格表用真实数据，抄用户给的就不改。
- 页脚固定：`taiwooeyewear.com | sales@taiwooeyewear.com | WhatsApp +86 13959244463`（换品牌时替换）。
- 禁忌词一个都不能出现：`FDA approved`、`cheapest`、`best in the world`。ISO 9001 是**体系**认证，不能写成产品认证。

## 检查点（进步骤 3 之前必须过）

- [ ] 页序表每一行文件名唯一，且前两位与页码一致、连续无缺号。
- [ ] 每个型号都在表上有明确页数，没有「待定」。
- [ ] 每个章节都有独立章节页。
- [ ] 页脚文案、品牌名、联系方式已确认。
- [ ] 全文没有禁忌词。
- [ ] 页数与 `render.cjs` 清单、`LABELS` 三处一致（或已排入待改清单）。

## 常见坑

- **先排版再定页序。** 页序表是排版的输入。边排边加页，等于把页码、目录、章节号全部返工。
- **文件名随手起。** 文件名是页码和目录标签的唯一来源，起名随意就得手动对齐三处清单。
- **文案留到排版时现写。** 排版时注意力在版式，写不出好文案。文案先落地成文本，排版只做搬运。
